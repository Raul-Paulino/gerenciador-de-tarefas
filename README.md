# 📋 Gerenciador de Tarefas Full-Stack

Um projeto de lista de tarefas (To-Do List) interativo e moderno, desenvolvido para consolidar os fundamentos de desenvolvimento web full-stack utilizando **Python (Flask)** no back-end e **HTML, CSS e JavaScript** no front-end.

---

## 🚀 Tecnologias Utilizadas

Este projeto foi construído com as seguintes tecnologias e ferramentas:

* **Python (3.15)** & **Flask** (Back-end / Servidor web)
* **HTML5** (Estruturação das páginas)
* **CSS3** (Estilização moderna com design responsivo)
* **JavaScript** (Interatividade dinâmica no navegador)
* **Git & GitHub** (Controle de versão e portfólio)
